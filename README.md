# creo-ai-connection

An AI agent skill for connecting to a running PTC Creo Parametric session through CREOSON/MCP or a version-matched native TOOLKIT controller, identifying the active model, and verifying authorized CAD operations.

用于 AI 连接 Creo Parametric、排查 CREOSON/MCP 连接，并核对目标会话、活动模型和已授权操作。

Read [SKILL.md](SKILL.md) for the workflow, requirements and scope. Supporting references, scripts and assets are included where applicable.
